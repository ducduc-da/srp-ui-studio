# 05 组件库与参考实现

## 1. 复用顺序

1. 项目已有业务组件。
2. 项目 `components/ui` 中已经封装并主题化的基础组件。
3. shadcn/ui 对应组件，经 SRP token 主题化后使用。
4. 只有前三者无法满足时才新增组件。

不得直接引入另一套完整设计系统，也不得让第三方组件默认色、圆角、字体和阴影进入正式页面。

## 2. 推荐基础组件映射

| 场景 | 组件 |
|---|---|
| 按钮/图标按钮 | Button |
| 单行/多行输入 | Input / Textarea |
| 模式与工作区分类 | Tabs |
| 重命名、确认 | Dialog / AlertDialog |
| 会话更多操作 | DropdownMenu |
| 右侧工作区、移动侧栏 | Sheet |
| 图标解释 | Tooltip |
| 分类、状态 | Badge |
| 轻提示 | Toast/Sonner |
| 左侧导航骨架 | Sidebar |
| 长列表 | ScrollArea；必要时虚拟列表 |
| 图表 | 项目现有图表封装；统一主题配置 |

## 3. 当前原型中的参考对象

研发应在实际项目中搜索对应文件并复用其最新版本，重点参考：

- 首页与主视觉：`app/kv-home.tsx`、`app/kv-home.css`
- 正式问答与图文报告：`app/qa-task.tsx`、`app/qa-refine.css`
- 侧栏悬浮操作：`app/sidebar-row-actions.tsx`、`app/sidebar-row-actions.css`
- 专题分析模块：`app/topic-modules.css`
- 资产中心：`app/skill-market.tsx`、`app/skill-market.css`（页面名称应显示“资产中心”）
- 公共组件：`components/ui/sidebar.tsx`、`tabs.tsx`、`dialog.tsx`、`dropdown-menu.tsx`、`button.tsx`

文件名可能随重构变化，搜索组件语义优先于复制旧代码。当前正式原型用于感受密度、灰度和留白；本文档与 token 是跨页面的一致性标准。

## 4. 新组件的准入

新组件必须：

- 能复用于至少两个业务场景，或承载明确的新交互范式；
- 使用 token 并覆盖完整状态；
- 提供键盘与可访问性行为；
- 有最小示例和边界说明；
- 不以业务页面名称命名基础组件。
