# 02 布局与导航规范

## 1. 页面骨架

桌面端统一采用：左侧栏 + 顶部操作栏 + 主内容区 + 可选工作区抽屉。页面背景为 `bg.canvas`，主内容不额外套一层巨型卡片。

| 区域 | 建议尺寸 |
|---|---|
| 展开侧栏 | 260px |
| 收起侧栏 | 48px |
| 顶部栏 | 52–56px |
| 正式问答正文 | 最大 820px |
| 首页输入区 | 最大 780px |
| 专题模块页 | 最大 1120px |
| 资产中心 | 最大 1180px |
| 工作区抽屉 | 320px；窄屏 280px |

首页首屏的核心输入区在视觉中心附近，不顶在页面上缘。正式问答页以连续阅读为主，内容自然从上向下展开。

## 2. 顶部栏

- 仅放全局或当前页面关键动作，例如分享、打开/收起工作区。
- 图标 15–17px，文字 12–13px，颜色使用 `text.secondary`。
- 操作之间 4–8px；纯图标按钮热区 28–32px。
- 不重复侧栏已有入口，不展示没有功能的装饰图标。
- 页面滚动时顶部栏可固定，但要保留 1px 弱分割线。

## 3. 左侧栏

- 品牌区包含搜索聊天和收起侧栏；收起后保留清晰的展开入口。
- 任务与最近对话可折叠；行高 34–36px，标题单行省略，时间位于右侧。
- 每个任务只占一行，不因专题/自由探索类型增加第二列或永久图标。
- 更多按钮绝对定位在行右侧，仅 hover、键盘 focus-within 或菜单打开时出现；出现时可覆盖时间，但标题宽度与位置不变化。
- “任务”和“最近对话”的标题文字必须共用同一条左侧起始线。图标或状态位采用悬浮槽位，不得让其中一组标题额外右缩进。
- 行在 default、hover、selected、focus、menu-open 等状态下使用完全相同的左右内边距；交互只改变背景、颜色或显示覆盖层，不得移动内容。
- 运行中显示青绿色旋转符号；失败显示红色提示；成功不保留状态图标。
- 菜单可包含：打开、重命名、保存到工作空间、分享、删除。危险动作置底并使用红色。

## 4. 工作区

标题为“工作区”，三个类目固定为：`最终产物`、`过程文件`、`我的上传`。保留既有紧凑标签页样式，不因文案调整改变组件外观。

- 标签字号 12–13px；选中态以浅背景/主色细线表达，不使用大色块。
- 文件行高约 35px，文件图标 14px，文件名 13px，单行省略。
- 文件列表以行呈现，不强制使用卡片；hover 可显示打开等次级动作。
- 工作区展开时主内容不整体左移；在桌面宽屏可从右侧占位，在窄屏作为覆盖式抽屉。

## 5. 搜索对话布局

- 搜索弹窗标题、说明、搜索框和结果列表共用同一内容左边界。
- 搜索输入文字、占位符始终左对齐；搜索图标固定在输入框左侧，不能使正文居中。
- 结果列表从搜索框内侧文字起始线开始排列，不居中、不使用逐项不同缩进。
- 结果图标使用固定宽度槽位；无图标时仍保持标题起始线一致。
- 搜索结果行的 hover、选中和点击状态不得造成文字向左或向右移动。

## 6. 页面模板

- 首页：模式切换 + 居中主输入 + 少量建议项。
- 正式问答：用户问题、可折叠思考过程、无气泡的 AI 正文、图表/表格、底部输入。
- 专题分析：筛选标签 + 3 列配置模块；≤1050px 两列，≤720px 单列。
- 资产中心：标题/说明 + 搜索 + 分类 + 3 列资源卡；不展示无关图片。
- 报告/产物：连续文档流，正文最大 820–900px；图表可扩展至正文宽度。

## 7. 响应式

- ≥1200px：完整侧栏和可并列工作区。
- 850–1199px：侧栏可收起，工作区宽 280px。
- <850px：侧栏与工作区均为覆盖式抽屉，不压缩正文。
- <720px：卡片单列，顶部次要文字可隐藏，关键动作不可丢失。
