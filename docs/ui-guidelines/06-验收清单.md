# 06 页面验收清单

研发 AI 在完成页面后逐项回答“通过/不适用/未通过”，未通过项必须说明原因。

## 视觉

- [ ] 页面只使用 `tokens.json` 中的基础色；新增色有书面理由。
- [ ] 主文字、次文字、弱文字层级清晰，没有大段纯黑或过浅正文。
- [ ] 字号、行高、间距、圆角和阴影符合规范。
- [ ] 多彩色仅用于语义状态、分类或图表，没有污染产品骨架。
- [ ] 无无关装饰图片、emoji 图标或混用图标风格。

## 布局与导航

- [ ] 使用既有顶部栏、侧边栏和页面骨架，没有重复入口。
- [ ] 主内容宽度合理，首页视觉居中，阅读页不过宽。
- [ ] 工作区类目为“最终产物 / 过程文件 / 我的上传”，且未擅改样式。
- [ ] 搜索弹窗标题、搜索框和结果列表左边界一致，输入与结果文字均为左对齐。
- [ ] “任务”和“最近对话”的标题使用同一条左侧起始线，没有多余空缺。
- [ ] 1440、1280、1024、768 宽度无明显错位或遮挡。

## 交互

- [ ] hover、focus、active、disabled、loading、empty、error 状态完整。
- [ ] 侧栏 `…` 只在 hover/focus 出现，且标题位置和宽度不跳动。
- [ ] 列表在 hover、selected、focus、menu-open、click 前后没有横向位移。
- [ ] 成功任务不常驻图标；运行与失败状态符合规范。
- [ ] 弹窗能用 Esc 关闭，菜单不越界，关闭后焦点回到触发器。
- [ ] 关键操作可用键盘完成，纯图标按钮有 Tooltip 和可访问名称。

## 对话与数据

- [ ] AI 回答没有外层气泡；思考过程默认收起且可展开。
- [ ] 图表有标题、单位、图例/直接标注、Tooltip 和来源说明。
- [ ] 图表容器、字体、坐标轴、网格线、颜色和间距符合 `数据可视化规范.md`，没有保留图表库默认主题。
- [ ] 图表不只依赖颜色表达，数据与文案没有溢出。
- [ ] 表格数字右对齐、文字左对齐，长内容可读。
- [ ] 表格表头、行高、分割线、hover 和空值写法保持一致。

## 文案

- [ ] 按钮使用明确动词，标题与状态名称全产品一致。
- [ ] 空、错、权限状态说明原因和下一步。
- [ ] 删除等高风险操作点明对象、后果和可恢复性。
- [ ] 无营销空话；虚构或演示数据已标记。

未通过项与原因：
