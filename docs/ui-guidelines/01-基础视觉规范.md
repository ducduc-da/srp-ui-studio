# 01 基础视觉规范

## 1. 设计气质

SRP 是面向研究与分析工作的专业工具。视觉关键词是：克制、清晰、可信、轻量。信息密度可以高，但必须通过灰度、留白和对齐降低认知负担。避免大面积渐变、高饱和背景、拟物装饰和营销页式视觉。

## 2. 色彩

| 用途 | Token | 色值 |
|---|---|---|
| 页面背景 | `bg.canvas` | `#FBFBFA` |
| 侧栏背景 | `bg.sidebar` | `#FBFCFC` |
| 内容表面 | `bg.surface` | `#FFFFFF` |
| 次级/悬浮表面 | `bg.subtle` | `#F3F5F5` |
| 选中表面 | `bg.selected` | `#EDF4F5` |
| 主文字 | `text.primary` | `#30363B` |
| 次文字 | `text.secondary` | `#687077` |
| 弱文字 | `text.tertiary` | `#929BA3` |
| 禁用文字 | `text.disabled` | `#A8ADB1` |
| 默认边框 | `border.default` | `#E3E7E9` |
| 弱分割线 | `border.subtle` | `#ECEEED` |

### 品牌与语义

| 用途 | Token | 色值 | 规则 |
|---|---|---|---|
| 品牌主色 | `brand.primary` | `#359DAC` | 主按钮、选中、链接、焦点 |
| 悬浮 | `brand.hover` | `#2E8D9C` | 主动作 hover |
| 浅品牌底 | `brand.soft` | `#EAF4F6` | 用户气泡、选中弱背景 |
| 成功 | `status.success` | `#3B9462` | 仅在需要明确成功语义时使用 |
| 运行 | `status.running` | `#2DB6B2` | 动态旋转状态 |
| 等待 | `status.warning` | `#E3A43A` | 等待、需关注 |
| 失败 | `status.danger` | `#D95768` | 错误、删除、失败提醒 |

### 搜索框与按钮用色

搜索框不是强调色容器。默认使用白色表面、灰色边框和主文字；只有输入焦点出现时才使用品牌青绿色边框与焦点环。

| 组件状态 | 背景 | 边框 | 文字/图标 |
|---|---|---|---|
| 搜索框默认 | `bg.surface` | `border.default` | `text.primary`；图标与占位符使用 `text.tertiary` |
| 搜索框 hover | `bg.surface` | `#CBD4D7` | 保持不变 |
| 搜索框 focus | `bg.surface` | `border.focus` | 输入文字 `text.primary`，外加 `brand.ring` |
| 搜索框 disabled | `bg.subtle` | `border.subtle` | `text.disabled` |
| 主按钮默认 | `brand.primary` | `brand.primary` | `text.inverse` |
| 主按钮 hover/active | `brand.hover` / `brand.active` | 同背景 | `text.inverse` |
| 次按钮默认 | `bg.surface` | `border.default` | `text.primary` |
| 次按钮 hover | `bg.subtle` | `#D6DCDE` | `text.primary` |
| 幽灵按钮默认/hover | 透明 / `bg.subtle` | 透明 | `text.secondary` / `text.primary` |
| 危险按钮 | `status.danger` 或浅红底 | 同语义色 | 白色或 `status.danger` |

主按钮不得使用纯黑、随意渐变或页面临时主题色。搜索框不得默认使用高饱和边框，也不得用阴影代替清晰的 focus 状态。

植物参考配色中的绿色、黄色、玫红、蓝紫可用于图表系列和分类标签；不得用作导航、普通按钮或大面积页面底色。同一图表优先使用青绿单色阶；只有需要区分类别时才使用多色。

### 对比与可访问性

- 正文与背景对比度至少 4.5:1；大号文字至少 3:1。
- 不只用颜色表达状态，失败需同时有图标或文字。
- 禁止纯黑 `#000000` 正文和低对比浅灰正文。

## 3. 字体与字号

字体栈：`PingFang SC, Microsoft YaHei, Inter, Arial, sans-serif`。数字与中文同一字体栈，不混用装饰字体。

| 层级 | 字号/行高 | 字重 | 场景 |
|---|---|---|---|
| 页面标题 | 26/36 | 600 | 首页、资产中心一级标题 |
| 模块标题 | 18/26 | 600 | 报告章节、弹窗标题 |
| 小节标题 | 15/22 | 600 | 卡片、问答小节 |
| 正文 | 14/22 | 400 | 对话、说明、报告正文 |
| 控件文字 | 13/20 | 400/500 | 导航、按钮、下拉 |
| 辅助文字 | 12/18 | 400 | 元信息、说明 |
| 时间/标签 | 11/16 | 400/500 | 侧栏时间、状态标签 |

禁止通过大量加粗表达层级。中文正文不使用全大写；英文产品名保留官方大小写。

## 4. 图标

- 优先使用项目统一线性图标库；同一区域不得混用不同风格。
- 常规图标 16px，紧凑图标 14px，重点入口 18px；默认描边 1.5px。
- 图标颜色继承文字颜色；主色只用于选中、运行或关键动作。
- 纯图标按钮点击热区至少 28×28px，并提供 Tooltip 与可访问名称。
- 更多操作统一使用横向 `…`；仅 hover/focus 出现。禁止用 emoji 作为图标。

## 5. 间距、圆角与阴影

间距以 4px 为基准：`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40`。组件内部优先 8、12、16；模块之间优先 24、32。

| 场景 | 圆角 |
|---|---|
| 侧栏行/菜单项 | 5–6px |
| 按钮/输入框/标签页 | 7–8px |
| 卡片/下拉菜单 | 10–11px |
| 输入主框/弹窗 | 16–18px |
| 圆形图标按钮 | 50% |

阴影只表达浮层层级：普通卡片以边框为主；下拉使用 `shadow.popup`；弹窗使用 `shadow.dialog`。禁止给所有卡片添加明显阴影，也禁止彩色发光阴影。

## 6. AI 回答中的图表与表格

图表和表格属于回答正文，不是独立应用，也不是装饰图片。它们必须继承正文宽度、字体、灰度和间距体系。

- AI 回答不添加外层气泡；单个图表可以使用白色表面、1px 边框、11px 圆角的内部面板。
- 图表标题 14–15px/600，指标说明、图例、单位和来源 11–12px；均使用产品字体栈。
- 坐标轴、网格线和表格分割线使用中性灰，不使用高饱和颜色。
- 默认数据系列以品牌青绿色为主；只有比较类别时才引入绿色、黄色、玫红、蓝色和紫色。
- 表格表头使用浅灰底，数字右对齐，文字左对齐；不使用厚边框和高对比斑马纹。
- 颜色不能成为唯一的信息编码，必须辅以标签、数值、图例或线型。

具体尺寸、颜色映射、图形类型和响应式规则见 `数据可视化规范.md`。
