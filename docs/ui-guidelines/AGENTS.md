# SRP 页面设计与实现约束

本文件约束 AI 在 SRP 产品中新增或修改页面。除非产品需求明确覆盖，以下规则均为强制规则。

## 开工前

1. 阅读本目录全部规范及 `tokens.json`。
2. 检索项目中已有布局、导航、表单、弹窗、下拉、图表和空状态组件。
3. 说明将复用哪些组件；只有现有组件无法表达需求时才新建组件。
4. 先确认页面属于：首页、正式问答、专题分析、资产中心或报告/产物页，再选对应骨架。

## 强制规则

- 使用设计 token，不在业务组件中散落新的十六进制颜色、阴影和任意间距。
- 产品骨架只使用中性灰、暖白和品牌青绿色。多彩色仅用于状态、分类标签和数据可视化。
- 页面标题、正文、辅助文字必须形成三级以上灰度层级，不用纯黑。
- 左侧任务标题始终占满原有文字空间；更多操作 `…` 仅在行 hover/focus 时悬浮出现，不得挤压或移动标题。
- “任务”、最近对话、搜索结果的标题共用一致的左对齐规则；任何点击、hover、选中或图标出现都不得造成标题横向位移。
- 搜索框、结果列表与弹窗内容左边界一致；搜索内容不得居中。
- 任务状态：运行中显示青绿色旋转状态；失败持续显示红色提醒；成功完成不保留重复图标。
- AI 正式回答不套外层气泡或大卡片；用户消息可以使用浅色气泡。
- AI 回答中的图表和表格必须遵循 `数据可视化规范.md`，不得直接使用图表库默认主题。
- 弹窗、下拉和 Tooltip 必须使用统一组件，不用浏览器默认样式。
- 新页面不得新增第二套顶部栏、侧边栏或重复的分享/抽屉入口。
- 动画只解释状态变化，默认 120–200ms；尊重 `prefers-reduced-motion`。
- 不以表情符号代替产品图标，不使用无关装饰图片。

## 允许例外的条件

只有业务语义无法由现有 token 或组件表达时才能例外。提交时需写明：问题、采用的例外、未复用现有方案的原因、后续是否应沉淀为公共能力。一次性页面不得反向污染全局 token。

## 完成定义

- 覆盖 default、hover、focus、active、disabled、loading、empty、error 状态。
- 键盘可操作，焦点可见；图标按钮有可访问名称。
- 在 1440、1280、1024、768 四个宽度完成目测。
- 无标题跳动、弹层越界、内容遮挡、滚动穿透和无意义常驻图标。
- 按 `06-验收清单.md` 输出自检结论。
