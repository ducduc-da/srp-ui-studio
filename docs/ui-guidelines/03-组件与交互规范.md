# 03 组件与交互规范

## 1. 按钮与输入

- 主按钮：`brand.primary` 青绿色底、白字，高 36–40px，圆角 8px；hover 使用 `brand.hover`，active 使用 `brand.active`；每个局部区域只保留一个主动作。
- 次按钮：`bg.surface` 白底、`border.default` 边框、`text.primary` 文字；hover 使用 `bg.subtle`。
- 幽灵按钮：默认透明、`text.secondary`；hover 使用 `bg.subtle` + `text.primary`，仅在工具栏或列表行使用。
- 危险按钮：确认执行删除时使用 `status.danger`；普通菜单中的危险动作仅使用红色文字，不提前制造大面积警示。
- 禁用态降低对比并取消阴影，不只降低透明度到难以辨认。
- 普通输入高 38–40px；正文 14px；默认白底与灰色边框；focus 使用 `border.focus` + 轻量 focus ring。输入值使用主文字色，占位符使用弱文字色。
- 搜索框内容一律左对齐；左侧搜索图标使用 16px 固定槽位。弹窗中的搜索框应占满内容宽度，不做居中短框。
- 对话输入框支持多行：首页向下增长；正式问答页底部输入向上增长；最多 8 行后内部滚动。

## 2. 对话与思考过程

- 用户消息可用 `brand.soft` 浅色气泡，最大宽度 72%，靠右。
- AI 回答直接进入文档流，不使用外层气泡、头像卡或重复的助手名称。
- 思考过程默认收起，显示“用时 1 分钟 43 秒 ›”；展开后呈现思考正文，再次点击收起。
- AI 正文标题 15–18px，正文 14/22；段落间 12–16px，章节间 24–32px。
- 图表本身可使用有边框的内部面板，但不能把整段回答框成一张大卡。

## 3. 弹窗

- 遮罩：黑色 10%–14%，可使用 2px 轻微模糊；禁止厚重黑幕。
- 标准宽度 420px；复杂表单最大 560px；圆角 18px；内边距 20px。
- 标题 18/26、600；说明 13/20、`text.tertiary`；关闭按钮位于右上。
- 表单与标题间 16px；按钮区距内容 20px，右对齐，按钮间 8px。
- 主按钮必须使用品牌青绿色，不使用与主题无关的深黑按钮。
- 打开后焦点进入首个控件；Esc 关闭；遮罩点击是否关闭由任务风险决定；删除需二次确认。

## 4. 下拉菜单与 Tooltip

- 下拉最小宽度 176px，内边距 5px，圆角 10px，使用 `shadow.popup`。
- 菜单行高 34px，字号 13px，图标 16px；hover 使用 `bg.subtle`。
- 分组用 1px 分隔线，不用大段留白；危险项红色并置底。
- Tooltip 只解释纯图标或被截断的内容；延迟约 400ms，文字 12px，保持一句话。
- 不用 Tooltip 承载必须阅读的说明，也不在移动端依赖 hover。

## 5. 卡片、标签页与列表

- 普通卡片以 `border.default` 为主，圆角 10–11px；hover 只做轻微边框/背景变化。
- 专题卡片：内边距 15–16px，标题 15/22，描述 13/20，字段标签 11–12px；卡片整体可点击时仍需有明显焦点态。
- 资产卡片保持等高，信息顺序为名称、简介、标签/作者、更新时间；不用无关封面图填充空间。
- 标签页使用文字 + 细线或浅底表达选中；文案变化不得导致组件换风格。
- 文件与会话优先用紧凑列表，不把每一项做成厚重卡片。
- 列表行的图标槽、文字槽、时间槽和悬浮操作槽应预先定义；任何槽位的显示/隐藏均不得改变标题起始位置。

## 6. 状态反馈

- Loading：局部骨架或青绿色旋转状态，避免整页遮罩。
- Success：任务完成后清除运行图标；只有明确保存/发布动作才短暂 Toast。
- Warning：说明风险与下一步，不只显示黄色图标。
- Error：红色图标/标题 + 可执行原因 + 重试或修复入口。
- Empty：说明“为什么为空”与主动作；不使用夸张插画。
- Toast 用于无需打断的短反馈；需要用户决策时使用弹窗，不用 Toast。

## 7. 图表与表格

本节为交互概要；视觉与数据表达细则以 `数据可视化规范.md` 为准。

- 图表标题 14–15px/600，副标题与数据来源 11–12px。
- 网格线使用 `border.subtle`，坐标文字使用 `text.tertiary`；重点数据使用主色。
- 类别不超过 6 个时使用离散配色；更多类别优先合并“其他”或使用同色阶。
- 条形图从零基线开始；折线图时间顺序从左到右；饼/环图类别建议不超过 5 个。
- Tooltip 必须显示维度名、数值和单位；不能只凭颜色辨认系列。
- 表格表头 12–13px/600，正文 13–14px；数字右对齐，文字左对齐；长表头允许换行。

## 8. 动效与可操作性

- hover/focus 120ms，弹层 160–200ms；不使用弹跳、漂浮等装饰动画。
- 可点击区域有 pointer、hover 与 focus-visible；禁用区域不可触发。
- 菜单、弹窗、抽屉打开后层级正确，关闭后焦点回到触发器。
