# SRP UI 规范｜AI 研发包

版本：1.0  
更新：2026-09-10  
适用：SRP 桌面端 Web 产品的新页面、功能迭代与设计还原

## 这套文件解决什么

当前产品页面是视觉参考，本规范把其中稳定的设计语言转成可执行规则，防止后续页面各自发挥。研发 AI 应先遵守规则，再参考页面观感；参考截图只说明意图，不得被当作逐像素组件库。

## 文件与阅读顺序

1. `AGENTS.md`：交给研发 AI 的强制执行协议。
2. `tokens.json`：颜色、字号、间距等机器可读的唯一值源。
3. `tokens.css`：可直接接入项目的 CSS 变量。
4. `01-基础视觉规范.md`：色彩、字体、图标、圆角、阴影。
5. `02-布局与导航规范.md`：页面骨架、顶部栏、侧边栏、工作区与响应式。
6. `03-组件与交互规范.md`：弹窗、下拉、气泡、表单、状态、图表等。
7. `数据可视化规范.md`：AI 回答中图表、表格与数据表达的完整规则。
8. `04-系统文案规范.md`：界面文字的口吻、结构与状态写法。
9. `05-组件库与参考实现.md`：组件复用顺序和现有实现索引。
10. `06-验收清单.md`：提交前的自检与验收标准。

## 规则优先级

当信息冲突时，按以下顺序执行：

1. 当前明确的产品需求；
2. 本规范中的“必须/禁止”；
3. `tokens.json` 中的设计变量；
4. 当前正式原型页面；
5. 第三方组件库默认样式。

临时截图、竞品截图只可用于解释布局或交互，不可直接带入其品牌色、字体、圆角和阴影。

## 推荐交付给研发的方式

- 将整个文件夹放入项目 `docs/ui-guidelines/`。
- 将本目录的 `AGENTS.md` 合并到项目根目录的 `AGENTS.md`，或在任务提示中明确要求先阅读它。
- 由工程侧把 `tokens.css` 接入全局样式；组件内不得重复发明颜色和间距值。
- 每次生成页面时，同时要求 AI 输出对照 `06-验收清单.md` 的自检结果。

## 可直接复制给研发 AI 的任务前缀

> 开始编码前，完整阅读 `docs/ui-guidelines/README.md`、`AGENTS.md` 和相关章节。复用现有组件及设计变量，不得自行新增品牌色、字号、圆角、阴影或导航结构。完成后按 `06-验收清单.md` 自检，并列出复用的组件、使用的 token、存在的例外及理由。
